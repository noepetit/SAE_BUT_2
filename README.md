## Pour les branches:    
* ```git checkout -b nomBranche```
  
Faire les modifs en local :    
* ```git add .```
* ```git commit -m "detail des modifs apporté"```
* ```git push origin nomBranch```
* ```gh pr create```
* ```gh pr merge --rebase --delete-branch```
